# ИНСТРУКЦИЯ ПО СОЗДАНИЮ ПРОФИЛЯ

## ШАГ 1: СОЗДАНИЕ РЕПОЗИТОРИЯ

1. Открыть https://github.com/new
2. В поле "Repository name" ввести: `atikin90`
3. Выбрать "Public"
4. Поставить галочку "Add a README file"
5. Нажать "Create repository"

## ШАГ 2: ЗАГРУЗКА README.md

1. Открыть созданный репозиторий https://github.com/atikin90/atikin90
2. Нажать на файл `README.md`
3. Нажать иконку карандаша (Edit this file)
4. Удалить всё содержимое
5. Вставить содержимое из файла `README.md` (из этого проекта)
6. Нажать "Commit changes..."
7. Нажать "Commit changes" в модальном окне

## ШАГ 3: СОЗДАНИЕ WORKFLOW ДЛЯ SNAKE

1. В репозитории перейти во вкладку "Actions"
2. Нажать "set up a workflow yourself"
3. Удалить весь код в редакторе
4. Вставить содержимое из файла `.github/workflows/snake.yml` (из этого проекта)
5. Нажать "Commit changes..."
6. Нажать "Commit changes"

## ШАГ 4: ВКЛЮЧЕНИЕ GITHUB ACTIONS

1. Перейти в Settings репозитория
2. Слева выбрать "Actions" → "General"
3. В разделе "Workflow permissions" выбрать "Read and write permissions"
4. Поставить галочку "Allow GitHub Actions to create and approve pull requests"
5. Нажать "Save"

## ШАГ 5: ЗАПУСК SNAKE ВРУЧНУЮ

1. Перейти во вкладку "Actions"
2. Слева выбрать "Generate Snake"
3. Справа нажать "Run workflow"
4. Нажать зелёную кнопку "Run workflow"
5. Подождать 1-2 минуты, пока workflow завершится (зелёная галочка)

## ШАГ 6: ЗАМЕНА КОНТАКТОВ

1. Открыть файл `README.md` в репозитории
2. Нажать иконку карандаша (Edit)
3. Найти строку: `https://t.me/YOUR_TELEGRAM_USERNAME`
4. Заменить `YOUR_TELEGRAM_USERNAME` на свой Telegram username (без @)
5. Найти строку: `mailto:YOUR_EMAIL@example.com`
6. Заменить `YOUR_EMAIL@example.com` на свой email
7. Нажать "Commit changes..."
8. Нажать "Commit changes"

## ШАГ 7: ЗАМЕНА ЗАКРЕПЛЕННЫХ ПРОЕКТОВ

1. Открыть файл `README.md`
2. Найти секцию "ЗАКРЕПЛЕННЫЕ ПРОЕКТЫ"
3. Заменить:
   - "Проект 1/2/3/4" на реальные названия
   - "Описание проекта" на краткое описание
   - "Стек: ..." на используемые технологии
   - `[Перейти к репозиторию →](#)` на `[Перейти к репозиторию →](https://github.com/atikin90/название-репозитория)`
4. Если проектов меньше 4, удалить лишние блоки `<td>...</td>`
5. Если проектов больше 4, скопировать структуру `<tr><td>...</td><td>...</td></tr>` и добавить новые строки

## ПРОВЕРКА

1. Открыть https://github.com/atikin90
2. Профиль должен отображаться с анимацией, графиками и snake
3. Если snake не отображается, подождать 12 часов (автоматический запуск) или запустить workflow вручную повторно

## ЧАСТЫЕ ПРОБЛЕМЫ

- Snake не отображается: проверить, что workflow выполнился успешно (зелёная галочка в Actions)
- Графики не загружаются: подождать несколько минут, сервисы могут быть временно недоступны
- Разметка сломана: проверить, что не добавлены лишние символы при копировании
